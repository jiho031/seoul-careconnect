정책 정보 오류

지원 대상, 필요 서류 등 정책 내용 오류는 정책 오류 관리에서 확인합니다.

기간 오류

신청 시작일과 마감일이 실제 공고와 다른 경우 정책 오류 관리로 연결합니다.

링크 오류

공식 신청 URL이 잘못되었거나 접속되지 않는 경우 정책 오류 관리로 연결합니다.

누락 정책 신고

서비스에 없는 정책은 수동 등록 또는 API 재수집 필요 여부를 확인합니다.

처리 흐름

신고 처리 기준
접수

신고가 등록되면 관리자가 신고 내용과 관련 정책을 확인합니다.

검토 중

정책 원문, 공식 URL 또는 API 원본 데이터와 신고 내용을 비교합니다.

처리 완료

정책 정보 수정 또는 누락 정책 등록이 완료되면 신고 상태를 처리 완료로 변경합니다.
