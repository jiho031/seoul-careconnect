누락 정책 신고

서비스에 없는 정책 신고는 수동 등록/수정 또는 API 재수집 대상으로 분류합니다.

중복 정책 신고

같거나 유사한 정책이 여러 개 노출된 경우 정책 예외 관리로 연결하여 병합 또는 제외 여부를 확인합니다.

담당 처리
